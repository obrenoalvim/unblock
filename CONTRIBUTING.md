# Contributing

`skills/web/SKILL.md` is the source of truth. Found a dead tool, a wrong order, or a free tool missing from the chain? Open a PR against it.

## What to contribute

- A free, keyless tool with no paid tier, worth adding to the chain
- A fix to the order (a tool that should run earlier or later)
- Removal of a tool that went paid, went dead, or stopped working
- A sharper line for the "when not to use" guard

## How

1. Fork the repo
2. Edit `skills/web/SKILL.md`
3. Open a PR that says what gap it closes and why
